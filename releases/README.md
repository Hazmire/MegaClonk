# Current Windows playtest

[Download Rewards and XP v7](https://github.com/Hazmire/MegaClonk/releases/download/rewards-ui-v7/BONK_INFINITY_Windows_x64.zip).

Extract everything and launch BONK_INFINITY.exe, or Launch_Compatibility.bat for OpenGL. Start a **new run** for the vertical terrain; version-3 checkpoints preserve their old maps.

Includes the five-tier rarity system, vertical forest/atmosphere/placement, blue/red XP gems, stacked level-up offers, chest roulette and shared shop/build interfaces. [Screenshots and guide](../docs/REWARD_UI.md).

See [provenance](BUILD_INFO.md), [checksum](REWARDS_SHA256SUMS), and [verification](REWARDS_VALIDATION.json). The downloaded ZIP passes archive, source and compiled-world/UI checks.
