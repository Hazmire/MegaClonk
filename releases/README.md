MEGACLONK — core overhaul and combat feedback

Extract the ZIP and launch BONK_INFINITY.exe. Use Launch_Compatibility.bat if Vulkan
is unavailable. No Godot installation, account or network is needed. Native Windows
execution is not tested in the cloud; packed resources are validated with Linux Godot.

WASD move, mouse camera, Space jump/glide, Ctrl crouch/slide, E interact, Q ultimate,
Escape pause/save, Tab build/stat tooltips, mouse wheel zoom, F11 fullscreen.
Controls are rebindable. Launch with --practice for the sandbox; F8 regenerates a map.

Choose one weapon, one trait and one ultimate. All traits/ultimates are available.
Each forest stage starts at10:00; rushes08:00/04:00, minibosses07:00/03:00, endless at0.
Find the purple portal and E to summon the main boss. Defeat it, then E at the mint
exit whenever ready to enter a harder seeded stage while retaining build and gold.
Colossus uses slam/charge/thorns; Sovereign uses dash/soul waves/marked explosion.

Gold belongs to the run; silver persists and comes from claimed quests. Silver buys
weapons and independent weapon/tome capacity:250 for slot3,750 for slot4. Shops use
gold, roll Common/Rare/Legendary and disappear after one successful purchase. Legendary
items grant a revival, periodic lightning or faster ultimate recovery. Weapon upgrade
cards choose actual eligible attributes; Tab tooltips show measured DPS without overkill.

Integrated supplied assets include Jacob, Kurland, ability/Undead icons, forest props,
Ancient Reliques, RPG sounds, PSX particles and Electric FX. Damage flashes red on the
player and all enemy types. VFX intensity/reduced effects are configurable. Original
enemies/bosses remain because the missing Quaternius download's storage is blocked.
Supplied loot scrolls cover tomes; the separate linked scroll pack is paid and absent.

Escape > Save run; Play > Resume saved run. V3 profiles migrate old credits/quest gold
into silver once. Data stays in %APPDATA%\Godot\app_userdata\BONK INFINITY\progress.json.
Run saves preserve stage, events, portals, encounters, build, abilities and consumed shops.
Transient projectiles/effects and recent DPS windows restart on loading.
