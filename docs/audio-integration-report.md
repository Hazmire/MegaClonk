# Audio integration (Fog pack) — implementation report

Branch `feature/audio-integration`. **Nothing here has been heard by a human.** Every check below is a headless test, a code read or a waveform measurement.
Scope was audio only: no gameplay, balance, UI layout or save-format change. The one place a sound needed a new read of game state (boss enrage) only reads HP; see section 5.

## 3. Judgement calls
- **Gains kept, pitch not.** Repointed events keep the old `cooldown`, `max_voices`, `priority` and `gain_db`. I did reset `base_pitch` to 1.0: the old values (0.82–0.9) were the "dark pass" and the new files are final. New events use the manifest's values; the manifest gives no `gain_db` for SFX/UI, so they use the engine default of −12 dB (music uses the manifest's −6 / −4). **Loudness check (section 8): several repointed events are now 5–7 dB quieter by peak than before; pickup.gold is the quietest.** Not changed, because you asked for the old gains to stay; this is the first thing to judge by ear.
- **Hurt threshold:** one hit that takes ≥ 18 % of max HP (after armour) plays `player_hurt_heavy`; anything else plays `player_hurt`. `Game.hurt` does not know the attacker, so "boss hit" cannot be told apart. Constant `RunAudio.HEAVY_HIT_FRACTION`.
- **Low HP heartbeat:** ≤ 30 % (the HUD overlay's own `LOW_HP_FRACTION`), pitch 1.0 at 30 % rising to 1.5 at 0 %.
- **Boss enrage:** fires once per stage boss (`kind == 8`) when its HP first falls to 25 % — the same line the boss bar uses for "ENRAGED" (`BossBar.LOW`). Roar per boss: stage 1 splits by boss (Big Chunkus, the largest → `bellow`; Rock Golem → `beast`), stage 2 → `shriek`, stage 3 → `abyssal`, and endless stages cycle through beast / shriek / abyssal. The ~0.5 s inhale is not trimmed. `boss_enrage_god` is unused (no final boss).
- **Stage-boss death and victory:** both sounds play only when the **last living stage boss** dies (the same condition that opens the portal, so a boss shrine with extra bosses plays them once, and minibosses never do). `stage_boss_victory` is delayed 2 s. Earlier bosses of a multi-boss stage die silently, as before. If you would rather hear `stage_boss_death` for every stage boss, `RunAudio.stage_boss_cleared` is the one place to change.
- **Footsteps:** the game has no ground-material data. Stage 1 → grass, later stages → dirt, steep ground (floor normal < 0.92, the old "rock" test) → stone. Wood is unused.
- **Slide:** the slide exists (`posture == "sliding"`), so `movement.slide` repoints the old scrape (restarted every 0.65 s) and `slide_recover` plays when a slide ends.
- **Level-up reveal:** one `ui.reveal_<tier>` for the best tier on the table, when the cards have landed (three overlapping bells would fight for one voice). Dealing is silent when the fanfare is skipped.
- **Chest:** the idle wobble is silent; `chest_hop` plays on the click that starts the jump and `chest_open` as the reel starts. Reel ticks use the per-item marker crossing the screen already had (`reel_spin_full` is not used, never both). Reveal plays `ui.reveal_<tier>`; `reward.applause` stays.
- **Imbue:** gem picked → `gem.pickup` (= `ui.gem_pickup`), fitting socket focused → `ui.socket_hover`, socket chosen → `ui.socket_place`, fuse → `imbue_fuse_<element>` or, when it completes a pair, `imbue_combo_<combo>`. Using an Imbued Amulet to open the second socket plays `socket_place` (the fuse sounds are 3–6 s long). `ui.imbue_fuse` is registered as the fallback but nothing plays it.
- **Gem-found popup:** `Game.gem_discovered` (vase, chest, shop gems) → `world.gem_found_<element>`.
- **Shrine:** loop pitch 1.0 → 1.25 with charge; ordered ticks at 20/40/60/80/100 %; leaving a part-charged shrine stops the loop and plays `charge_cancel`; completing plays `world.shrine_complete` (before the stat screen opens). State is kept in `ShrineCharging.audio_state`, never in the shrine object (saves unchanged).
- **Gold:** `ui.gold_pickup` replaces the old gold sound; the 3 files are ordered by streak (a pickup within 1.2 s of the last raises the step, capped at 3rd).
- **Ultimates:** only Nova (the 15 m blast) plays `weapon.ult_cataclysm`; Ghost and Berserk keep `combat.explosion`.
- **Lightning:** `lightning_strike` already contains the rolling thunder, so the separate delayed `weapon.lightning.thunder` was retired.
- **Menu names:** `MenuScreen.sfx(name)` now maps a name to an event id through one table (`MenuScreen.SFX`); the old string-concatenation (`"ui."+name`) is gone. `deny` used to hit an event that did not exist (silent); it now plays `ui.cant_afford`. Every loadout dropdown pick plays `ui.weapon_select`.
- **Weapons:** Bow plays `bow_volley` when the projectile count is > 1; Shotgun's `shotgun_pump` plays at 30 % of the cooldown (max 0.3 s); the Aura holds `aura_loop` while equipped and pulses `aura_pulse` per tick; Scythes loop `scythe_spin_loop` pitched with the fastest scythe's speed (0.85–1.35); Firestaff's optional `fireball_flight_loop` is on. Sword swing / hit are ordered by slash index in the burst and the last slash of a multi-slash burst plays `sword_swing_final`. Arrow hits are ordered by the number of enemies already pierced.
- **Element layers:** emitted from the same place as the weapon sounds (attack sites in `weapon_runtime.gd`, hits in `WeaponFeel.impact`). Aura pulses emit one attack and one hit layer per pulse (not one per enemy). Two gems emit both layers. No allocation per hit: ids and loop keys are precomputed.
- **Loops stop with the simulation:** `Game._physics_process` calls `silence_loops()` whenever the mode is not `run` (pause, level-up, shop…), and the weapon/shrine/heartbeat code restarts them next frame.
- **Voice protection:** a gameplay (non-UI-bus) sound can no longer steal a voice playing on the UI bus, whatever its priority. Music is not in the pool at all (two dedicated players). Music events passed to `emit` are rejected.

## 4. Retired
135 files deleted (full list: `docs/audio/FOG_RETIRED_FILES.json`): the curated Pixel Combat weapon clips, old UI / pickup / player / footstep / chest / socket sounds the pack replaces, the old music (`assets/audio/music/*`, `playlist.json`) and the two loose root WAVs. Events removed: `weapon.lightning.thunder`, `imbue.install`, `imbue.interact`, `reward.chest.reveal`, `reward.chest.legendary`. Left in place on purpose: everything under "events that stay", the legacy ambience, and the unused `sfx/enemy/*` and legacy enemy-death clips (they were already unreferenced and excluded from export). `docs/audio/WEAPON_CURATION.json` gained a `retired_by_fog_pack` block; `SOURCE_INVENTORY.json` lists source reels, still the origin of the clips that remain, so it is unchanged. `assets/audio/sfx/ATTRIBUTION.txt` now also describes the Fog pack (original, no third-party licence).

## 5. The one new read of game state
`RunAudio.check_enrage` is called from `Game.hit` for stage bosses after damage. It reads `hp` / `max_hp`, sets `e["enraged"]=true` once and emits a sound. It does not change damage, the RNG or any other state. All other hooks sit at places that already existed.

## 6. Music
Two players on the `Music` bus. States: **menu** (`main_menu_loop`, never restarted between screens) → **stage N** (`stageN_a`, then B, then A…, each handover a 3 s crossfade starting 3 s before the end; stage N uses pair `((N-1) mod 3)+1`; a new stage starts on A; re-entering the same stage does not restart) → **level-up** (`level_up_loop` swaps in under `levelup_toll`; closing resumes the stage track at the saved position) → **death** (`death_loop` 3.5 s after `player_death` starts) / **victory** (`menu` loop 8.5 s after the fanfare). Pause ducks the Music bus 8 dB with a low-pass at 4.5 kHz (an `AudioEffectLowPassFilter` + `AudioEffectAmplify` on the Music bus, tweened over 0.3 s). Per-track `gain_db` comes from the manifest. The Music bus sits 8 dB under the others at equal slider positions (`RetroAudio.MUSIC_OFFSET_DB`). The Settings sliders drive the buses exactly as before (`volumes()`).
Timing uses a virtual elapsed counter, so the state machine is testable with the Dummy audio driver; the real `playback_position` is not used.

## 7. Missing / unwired trigger points (nothing was invented)
- **No final stage and no final boss.** The game is endless (`advance_stage` just increments `stage`) and nothing calls `finish_run(true)` outside a test. So `music.boss_the_god_below` and `world.boss_enrage_god` have no trigger. `music_victory()` exists and is tested, but no game path reaches it; the victory fanfare is played at the last stage boss as you specified.
- `ui.type_key`, `ui.type_bell`: no typewriter text effect exists. `ui.memo_hover`, `ui.stamp_done`, `ui.stamp_not_yet`: registered and in the `MenuScreen.SFX` table but nothing calls them (no stamp animation; quest memo cards have no hover hook).
- `weapon.shotgun_knockback`: the Shotgun has no knockback in the game.
- `movement.step_wood`: no wooden surface.
- `ui.reel_spin_full`: deliberately unused (ticks are timed).
- `ui.imbue_fuse`: fallback only.
- The Imbue fuse animation lasts 0.9 s but the fuse sounds last 3.3–6.2 s, so the anvil strike and the animation will not line up. I did not change the animation.
- `world.boss_enrage_*` is for stage bosses only; minibosses stay silent.
