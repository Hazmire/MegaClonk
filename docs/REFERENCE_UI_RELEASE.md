MEGACLONK — Reference UI Playtest 7.1

Uses all five reference screenshots uploaded to GitHub to refine the pause, expanded world map, inventory, shop, upgrade and chest interfaces. Adds a large PAUSED title, sidebars, bevelled action buttons, coloured upgrade actions, clear gold prices/progression, and empty/locked equipment slots.

Press M (rebindable) to inspect the discovered world. Opening it from pause returns to pause; opening from gameplay resumes gameplay when closed. The map preserves fog of war, shows elevation shading and distinct landmark markers, and keeps simulation paused. Existing combat, rewards, prices, progression and saves are preserved.

The reference screenshots inform the design and are excluded from the playable pack. Includes 27 focused UI checks and the existing full regression suite; compiled-pack smoke now covers pause/map and verifies reference-image exclusion. Native Windows execution, physical controllers and gaming-GPU 60FPS remain unverified. The known Mesa sky-texture shutdown diagnostic remains.

Extract the ZIP and launch BONK_INFINITY.exe, or Launch_Compatibility.bat for OpenGL. See REFERENCE_UI.md and REWARD_UI.md for usage, screenshots and limits.
