MEGACLONK terraced Forest playtest: flat plateaus, wide straight ramps, seeded connected routes, physical cliffs and forest clusters. Supplied Ranger with skeletal animations; Imp/Puglin with shared animated horde rendering. Existing menus, traits, ultimates, sixteen enemy behaviours, ten-minute stages, shops, bosses and progression are retained.

Download **BONK_INFINITY_Windows_x64.zip**, extract all files, and launch **BONK_INFINITY.exe**. Use **Launch_Compatibility.bat** if Vulkan is unavailable. No Godot installation is required.

100 generated layouts and 100 physical worlds are checked for connectivity, collision and native navigation, alongside gameplay regressions and ramp/animation checks. Rendered appearance inspected under Linux software OpenGL. Native Windows execution and target gaming-PC performance still need playtesting.

The supplied Bestiary Standard pack contains two species; behaviour variants share those models. Ranger uses a head from the supplied animation mannequin. Full details/licences are included in the ZIP and docs/FOREST_OVERHAUL.md.
