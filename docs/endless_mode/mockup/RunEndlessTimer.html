The endless timer

ONE TIMER · NO BANNER · IT TURNS RED AT 10:00 AND COUNTS UP

No second timer and no announcement text. When the run timer reaches 10:00 it glitches for half a second, then becomes the endless timer: blood red, reset to 00:00, counting how long you have survived. The line under it changes from the stage number to ENDLESS. The ghosts arriving does the rest.

PAUSE STRIP · RESULTS HEADLINEIn the pause strip, Time becomes Endless. Results lead with the endless time; the 10:00 before it is a given.
IT GETS WORSE THE LONGER YOU LASTThe timer escalates with the ghost tiers, at endless 3, 6 and 10 minutes. Each step replays the 0.5 s glitch, so the player sees it change. The colour runs from bright blood red down to near-black. The effects stay on the timer and never spread over the play area.

SIZE AND PLACESame position, font and size as the run timer (IM Fell English 68 px). Only the colour, the count and the line underneath change, so nothing on the HUD moves.
COLOURDigits #D8333E with the HUD's ink shadow and a faint red glow; ENDLESS in the alert pink #E07B83; the rules stay rust #B3363F.
SOUNDOne existing cue on the switch, for example the boss warning, so a player who isn't looking at the top of the screen still knows. Optional.
