MEGACLONK — Combat and Atmosphere Playtest

Cached/pooled enemy deaths, instanced aggregated damage numbers, merged XP with full rewards, gravity-based cliff dropping, four simple player animations, themed weapon effects and actual Chunkers rocks/debris. Forest ground has soil/moss variation and sparse wind grass; dark blue sky, distance fog and much taller irregular rocky boundaries are included.

Download BONK_INFINITY_Windows_x64.zip, extract everything, and launch BONK_INFINITY.exe. Launch_Compatibility.bat selects OpenGL. No Godot installation is required.

CPU death stalls dropped from roughly300–390ms to under1ms in controlled tests. This is not a gaming-GPU FPS guarantee. Native Windows/audio/hardware performance still needs local playtesting. Mesa software OpenGL reports two retained texture handles on shutdown; this unresolved diagnostic is documented in the included performance report.
